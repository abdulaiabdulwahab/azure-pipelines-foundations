# Azure Pipelines Foundations Project

## Overview

This project is a simple hands-on introduction to **Azure Pipelines**.

The goal is to learn how to create a basic CI pipeline that automatically runs whenever code is pushed to the `main` branch.

The pipeline will:

* Check out the source code
* Configure Python
* Install dependencies
* Run automated tests
* Run the application
* Create a build artifact
* Publish the artifact in Azure DevOps

## Application

The project contains a simple Python calculator with basic addition and subtraction functions.

Example:

```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b
```

Run the application locally:

```bash
python src/calculator.py
```

## Install Dependencies

Install the required Python packages:

```bash
python -m pip install -r requirements.txt
```

The main dependency used in this project is:

```text

```

## Run Tests Locally

Run the automated tests with:

```bash
pytest -v
```

A successful test run should show:

```text

```

---

## Azure Pipeline

The pipeline is defined in:

```text
azure-pipelines.yml
```

The pipeline automatically runs when code is pushed to the `main` branch.

The workflow is:

```text
Git Push
   ↓
Azure Pipeline
   ↓
Checkout Repository
   ↓
Configure Python
   ↓
Install Dependencies
   ↓
Run Tests
   ↓
Run Application
   ↓
Create Artifact
   ↓
Publish Artifact
```

## Pipeline Artifact

After a successful pipeline run, Azure Pipelines creates an artifact named:

```text
calculator-output
```

The artifact contains:

```text
result.txt
```

This file contains the output generated by the Python application.

## Troubleshooting

### Pipeline Does Not Start

Check that your current Git branch is:

```bash
git branch
```

The pipeline is configured to trigger on:

```text
main
```

---

### Tests Fail

Run the tests locally:

```bash
pytest -v
```

Check the failed test and correct the application or test code.

---

### Dependency Installation Fails

Check that `requirements.txt` exists and contains:

```text
pytest
```

Then test locally:

```bash
python -m pip install -r requirements.txt
```

---

### Artifact Is Missing

Check the pipeline logs and confirm that the artifact creation and publishing steps completed successfully.

Useful debugging commands include:

```bash
pwd
ls -la
```
